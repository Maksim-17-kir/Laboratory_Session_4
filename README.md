# Домашнее задание к работе 4

## Условие задачи

**Фабрика игрушек**

Контроль качества на фабрике игрушек пропускает партию, если вес каждой из трех случайно выбранных игрушек (A, B, C грамм) кратен семи. Это свидетельствует о соблюдении технологических норм. Запишите условие принятия партии.

**Написать и отладить программу, которая проверяет, кратны ли три введенных числа A, B и C числу 7.**

---

## 1. Алгоритм и блок-схема

### Алгоритм решения

**Начало**

1. **Объявить переменные:**
   * `A`, `B`, `C` — *целые числа (вводятся пользователем)*
2. **Ввести исходные данные:**
   * `Ввод A, B, C`
3. **Проверить условие:**
   * `A % 7 == 0 И B % 7 == 0 И C % 7 == 0`
4. **Если условие истинно:**
   * `Вывод: "Числа кратны 7"`
5. **Если условие ложно:**
   * `Вывод: "Числа не кратны 7"`
6. **Сделать паузу для просмотра результатов:**
   * `system("pause")`
7. **Конец**
